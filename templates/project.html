◈ THE PROJECT

Behavioral Biometrics-Based
Intrusion Detection.

A keystroke-dynamics authentication system that detects intruders. Sentinel is the working prototype of this project — it profiles the millisecond rhythm of a user's typing and scores every later login attempt against that profile.
